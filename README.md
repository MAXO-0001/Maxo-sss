# MAXO — سلف + پنل وب

## چی اضافه شد؟

- `bot.py` — همون سلف قبلی، با چند اضافه‌ی کوچیک:
  - جدول دائمی `deleted_log` برای نگه‌داشتن تاریخچه‌ی پیام‌های واقعاً حذف‌شده (رفتار قبلی توی خود تلگرام دست‌نخورده، این فقط یه کپی برای پنل وب نگه می‌داره — حداکثر ۱۵۰۰ رکورد آخر).
  - یک ترد جدا که پنل وب رو بالا میاره (بعد از این‌که سلف کامل لاگین شد).
- `web.py` — بک‌اند پنل (Flask)، فقط API و صفحات را سرو می‌کند.
- `panel_utils.py` — تبدیل متن غنی (بولد/نقل‌قول ترکیبی) بین ادیتور وب و entities تلگرام.
- `templates/`, `static/` — رابط کاربری پنل (سیاه‌وسفید).

هیچ‌چیزی از رفتار سلف داخل تلگرام حذف نشده؛ همه‌ی دستورات قبلی («روشن»، «بلاک»، «سکوت»، ...) دقیقاً مثل قبل کار می‌کنن. پنل فقط یه راه دوم برای همون کنترل‌هاست.

## متغیرهای محیطی (Environment Variables روی Railway)

قبلی‌ها (بدون تغییر):
```
API_ID
API_HASH
SESSION_STRING
```

جدید (برای پنل):
```
PANEL_USERNAME       # نام کاربری ورود به پنل
PANEL_PASSWORD       # رمز عبور ورود به پنل
PANEL_SECRET_KEY     # یک رشته‌ی تصادفی و طولانی، برای امضای session (پیشنهاد: با `openssl rand -hex 32` بساز)
```

اختیاری:
```
PANEL_ENABLED         # پیش‌فرض 1 — برای خاموش کردن کامل پنل بذار 0
DELETED_LOG_MAX_ROWS  # پیش‌فرض 1500 — سقف رکوردهای آرشیو دائمی حذف‌شده‌ها
```

اگر `PANEL_USERNAME` یا `PANEL_PASSWORD` خالی باشن، پنل اصلاً بالا نمیاد (فقط سلف اجرا می‌شه) و توی لاگ همین موضوع نوشته می‌شه.

## دیپلوی روی Railway

1. همه‌ی فایل‌ها رو جایگزین نسخه‌ی قبلی توی ریپو/سرویس کن.
2. متغیرهای بالا رو توی تب Variables ست کن.
3. بعد از دیپلوی، توی تنظیمات سرویس روی **Generate Domain** بزن تا یه آدرس عمومی بگیری (Railway به‌صورت خودکار متغیر `PORT` رو ست می‌کنه و `bot.py` همون رو برای پنل استفاده می‌کنه).
4. با همون آدرس + `PANEL_USERNAME` / `PANEL_PASSWORD` وارد پنل شو.

## نکته امنیتی

پنل با رمز عبور ثابت محافظت شده و هیچ اطلاعات ورود تلگرامیِ شخص دیگری رو نمی‌گیره — فقط همون یک سشن (`SESSION_STRING`) که خودت از قبل ساختی رو کنترل می‌کنه. پیشنهاد می‌شه دامنه‌ی Railway رو با کسی به‌اشتراک نذاری و `PANEL_PASSWORD` قوی انتخاب کنی.
